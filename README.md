## 🚀 How to Collaborate Safely

To avoid breaking each other's code, please follow these workspace rules:

1. **Clone the repository** to your local machine:
   ```bash
   git clone https://github.com
   ```
2. **Create a separate branch** for your feature before writing any code:
   ```bash
   git checkout -b feature-yourname
   ```
3. **Commit and push** your changes to your own branch when ready:
   ```bash
   git add .
   git commit -m "feat: complete core logic for my assignment"
   git push origin feature-yourname
   ```
4. **Open a Pull Request (PR)** on GitHub so the team can review and safely merge your code into `main`.
